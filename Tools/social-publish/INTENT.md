# Sanitized intent

Build a small, harness-neutral Python 3.9+ YouTube CLI for user-operated desktop
OAuth, channel inspection, private uploads, status inspection, and deliberately
confirmed publication. All account operations must bind to one expected channel.
Local tokens and upload receipts belong in protected storage outside Git trees.
The public source, examples, and tests contain only synthetic data.

This is a conventional greenfield scope. The parent reported that its PDD intent
plan found no matching prompt ownership; this scope does not adopt or change PDD.
No live authentication, dependency installation, upload, or publication is part
of implementation acceptance.
