# claw-work

A public monorepo for reusable code, tools, experiments, and other material
generated by AI agents and harnesses (Ernest Yeung's bots).

See the [agent instructions](AGENTS.md), [bot contribution rules](BOTS.md),
and [public/privacy boundary](PRIVACY.md).

## Projects

- [CUDA llama.cpp deployment](Deployments/Scripts/llama-cpp-server/README.md): moved
  profile-driven launcher, local GGUF auditing, measured model checks and Pi setup.

- [Native Nemotron Rust library and server](Rust/claw-lm/README.md): original CUDA C++
  kernels, three decoding modes and a local OpenAI-compatible API; no PyTorch.

- [Personal Files](Rust/personal-files/README.md): Finder-inspired Ubuntu file
  browser in Rust and GTK 3. Favorites, recent and frequent places, tabs, path
  copy, and local skins. Per-user install; it does not replace the system file
  manager.
- [Personal Files for macOS](Rust/personal-files-macos/README.md): native Rust
  and AppKit file browser with editable paths, SMB/Keychain integration, tabs,
  independent windows and standard macOS tiling. Per-user application bundle;
  separate from the Ubuntu version.
- [Lean agent toolkit](Rust/lean-agent/README.md): mathlib-enabled Docker environment,
  Rust-first isolated proof checking and mathematical code-review workflows.
  [Local setup for Claude Code, Codex, Grok Build, Hermes and Pi](Rust/lean-agent/docs/SETUP.md)
  includes native ARM64/x86-64 images, shared CLI tools and two portable skills.
- [llama.cpp server for macOS](Deployments/llama-cpp-server-macos/README.md): run
  local GGUF open-weight models natively on Apple Silicon (Metal), resolved from the
  HuggingFace hub cache, behind OpenAI- and Anthropic-compatible APIs. Includes the
  `llama-cpp-macos` skill for connecting Claude Code, Codex, Grok Build, Hermes and pi.
- Short-form video (faceless TikTok, Reels, Shorts), moved here from Monoclaw on
  2026-11-14. Two skills, installed with `skills/install-shortform-skills.sh` for
  Claude Code, Codex, Grok Build, Hermes and Pi:
  [`short-form-strategy`](skills/short-form-strategy/SKILL.md) plans hooks,
  retention, engagement and script rhythm;
  [`claw-shorts`](skills/claw-shorts/README.md) produces the video. Its tools:
  [`Rust/claw-shorts`](Rust/claw-shorts/README.md) (voiced explainers with
  validated copy, canvas path, -14 LUFS audio),
  [`Rust/shortform-video`](Rust/shortform-video/README.md) (stock B-roll and Ken
  Burns photos, TTS, burned captions), [`Rust/claw-edit`](Rust/claw-edit/README.md)
  (transcript cuts) and the canvas renderer. Research notes and the ingest tool:
  [`docs/shortform/`](docs/shortform/README.md),
  [`Scripts/shortform-ingest/`](Scripts/shortform-ingest/README.md).

The Lean toolkit distinguishes proofs about mathematical models from verification
that source code implements those models. Read its verification status before relying
on any result. Git scope follows [AGENTS.md](AGENTS.md) and [BOTS.md](BOTS.md):
Cursor and hosted Grok automation use feature branches, and a human-directed
local harness may merge and ordinary non-force push to master when explicitly asked.

## Publishing tools

  Offline-tested; live authorization and uploads are not yet verified.
