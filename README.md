# claw-work

A public monorepo for code and other material generated by AI agents and harnesses (Ernest Yeung's bots).

Public, reusable agent-authored tools and experiments. See [agent instructions](AGENTS.md)
and the [public/privacy boundary](PRIVACY.md).

See [BOTS.md](BOTS.md) for the rules bots follow when contributing.

## Projects

- [CUDA llama.cpp deployment](Deployments/Scripts/llama-cpp-server/README.md): moved
  profile-driven launcher, local GGUF auditing, measured model checks and Pi setup.

- [Native Nemotron Rust library and server](Rust/claw-lm/README.md): original CUDA C++
  kernels, three decoding modes and a local OpenAI-compatible API; no PyTorch.

- [Lean agent toolkit](Rust/lean-agent/README.md): mathlib-enabled Docker environment,
  Rust-first isolated proof checking and mathematical code-review workflows.
  [Local setup for Claude Code, Codex, Grok Build, Hermes and Pi](Rust/lean-agent/docs/SETUP.md)
  includes native ARM64/x86-64 images, shared CLI tools and two portable skills.
- [llama.cpp server for macOS](Deployments/llama-cpp-server-macos/README.md): run
  local GGUF open-weight models natively on Apple Silicon (Metal), resolved from the
  HuggingFace hub cache, behind OpenAI- and Anthropic-compatible APIs. Includes the
  `llama-cpp-macos` skill for connecting Claude Code, Codex, Grok Build, Hermes and pi.
- [claw-shorts](Skills/claw-shorts/README.md): create 9:16 vertical short-form videos
  (TikTok, Reels, Shorts) from raw takes, screen recordings, or HTML/Canvas animations.
  Non-destructive workflow with paced captions, safe-zone margins, and deterministic
  output naming. Includes the `claw-shorts` skill for Claude Code, Codex, Grok Build,
  Hermes and Pi.

The Lean toolkit distinguishes proofs about mathematical models from verification
that source code implements those models. Read its verification status before relying
on any result. Development happens on feature branches; the repository owner merges.
