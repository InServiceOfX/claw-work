## Screenshot selection: success criterion

Screenshots are chosen by content (transcript cue points, ffmpeg scene changes,
and a dense 0.5 to 1s frame review, or a frame-by-frame check where text
flashes quickly), not at a fixed frequency.

**Success criterion:** any frame that shows an on-screen list or key data
(numbered lists, payouts, analytics, prices) must be captured **legibly**. If
the list scrolls or builds up over several frames, capture each distinct part
so every item can be read, and transcribe every item into the notes. Keep
screenshots unredacted. Creator figures such as payouts are kept as data.
