## What the signals say

These are correlations from about 30 videos, not causal claims.

1. **Saves are the reading-list signal.** Both 1.2M-view videos are "install this
   skill" content with 6–8% save rates: people keep them to come back to. That is
   the audience a reading list serves.
2. **Showing the source on screen is common at the top.** Both leaders show the
   GitHub page itself. "Fact or Hype?" builds its format around that.
3. **Keyword-gated CTAs inflate comments.** The two highest comment rates are
   @abloommedia (3.0%, "comment EDIT") and @adamstewartmarketing (1.2%, "comment
   CLAUDE"). Discount them as interest signals.
4. **Length isn't fatal.** Chase AI's 14-minute TikTok reached 253.7K views at a
   7.1% like rate.
5. **Interest compounds.** The top two were posted in September. "What I'm reading
   this week" is honest framing for older videos; "new this week" would not be.

### Produce it

1. **Faceless (preferred):** write a [`Rust/claw-shorts`](../../Rust/claw-shorts/README.md)
   spec with one scene per row of the table above. The VO column becomes
   `narration`, and the on-screen column becomes the scene text. Narration comes from
   `voxcpm-tts` (installed on the Mac mini), and each scene lasts as long as its
   narration. Run `claw-shorts check --spec … --strict`, then `render`. Add a
   synthetic-voice disclosure.
2. **Alternative (template path):** screen-record each page for 6–10 s (public
   pages only, no logged-in UI), join the clips with FFmpeg, then add cards:

   ```bash
   python3 skills/claw-shorts/scripts/claw_shorts.py render \
     --input joined.mp4 --output ./output/ --template step_breakdown \
     --title "5 things I'm reading - W45" \
     --steps "animate,HyperFrames,brag,Design skills,Weight-space programming" \
     --cta "Links below - new list every week"
   ```

3. Keep all recordings, narration and renders outside the repo.
4. Check that every on-screen number matches the tables in this file. Keep text
   inside the safe zones (no captions in the bottom ~20% or behind the right-side
   buttons).
5. Post by hand on TikTok. On YouTube, upload as private (the
   [YouTube CLI](../../Tools/social-publish/README.md) only uploads as private), review, then publish.
