# The "N things I'm reading this week" format

Researched 2026-11-09. Sources are linked below. Vendor guides are marketing-grade
advice, not controlled platform data.

## Where the format lives today

| Example | Medium | What it does well | Source |
| --- | --- | --- | --- |
| "What I read this week" (John Ma, AI Artifact) | Weekly newsletter | Sorts AI items by category with one takeaway each. Closes with "3 things I'm taking into next week" and states plainly that it's a reading list, not original research | [Post, 2026-11-09](https://johnmaartifacts.substack.com/p/what-i-read-this-week-taste-is-the) |
| "Weekly / Top N GitHub Repos / Week NN" | Weekly newsletter | Fixed, numbered weekly series. Edition number is in the title. Only includes repos that first shipped within the past year | [Week 18, 2026](https://advantageai.substack.com/p/weekly-top-12-github-repos-week-18) |
| Weekly trending AI repo trackers | Leaderboard pages | Ranks by stars gained in the last 7 days. This is a measurable "interest" rule, not a vibe | [OSS Insight](https://ossinsight.io/trending/ai) |
| `#whatireadthisweek` on TikTok | Short video | Mostly BookTok book roundups, not tech. The tech/AI version of the phrase is an open lane on TikTok | [TikTok tag](https://www.tiktok.com/discover/what-i-read-this-week) |
| "Fact or Hype?" (@itstundealao) | Short video | Closest adjacent short-form format: shows the source on screen, live test, cost display, binary verdict | [Our analysis](../../research/tiktok-itstundealao-2026-11-06/themes/03-fact-or-hype-format.md) |

A search on 2026-11-09 did not find an established TikTok creator running a
**tech/AI** "things I'm reading this week" series. The newsletter version is
common, and the TikTok phrase is dominated by books. Treat that as an opportunity,
not as evidence that the format performs.

## Structure we use

Taken from the listicle guidance and the newsletter examples above:

1. **Hook (0–3 s).** State the count and tease #1: "5 things I'm reading this
   week. Number one: …". Show the payoff visual in the first seconds, with no
   intro runway.
2. **Countdown #5 → #2 (~6–8 s each).** On screen: number + source name/URL, one
   benefit-first line, and `via @creator`. Each item pays off on its own, so a
   viewer who leaves early still got something.
3. **#1 (~10–12 s).** Longest slot and visually distinct. Include its caveat; that's
   the "worth reading carefully" part.
4. **Close (~3 s).** "Links in the description / pinned comment. New list every
   [day]." The recurring slot is the series promise.

Guidance behind the numbers:

- 5 or 10 items, about 5 s each, with #1 longest and revealed last
  ([FluxNote listicle guide](https://fluxnote.io/guides/youtube-shorts-listicle-format-2026)).
- High-retention Shorts tend to run 15–45 s. Re-hook wherever retention drops; a
  countdown is itself a sequence of re-hooks
  ([OpusClip](https://opus.pro/blog/ideal-youtube-shorts-length-format-retention),
  [Socialync](https://www.socialync.io/blog/short-form-video-structure-guide-2026)).
- A hook only works if the content pays it off
  ([Subscribr](https://subscribr.ai/youtube-strategy/scripting-youtube-shorts-engagement)).

Our ~50 s target is above the 15–45 s band because each item carries a source.
If retention data says otherwise, cut to 4 items or move the caveat to the
description.

## Platform differences

| | TikTok | YouTube Shorts |
| --- | --- | --- |
| Links | Not clickable in captions; use a pinned comment or link in bio | Put them in the description; viewers open it from the Short |
| On-screen URL | Required: it's the only way to "read" from the video | Still shown, since many viewers never open the description |
| Series signal | Same hook phrase + same week label every edition | Add each edition to a "Weekly reading" playlist |
| Visual polish | Casual screen recording is fine | Slightly more produced (clean cuts, consistent type) |
