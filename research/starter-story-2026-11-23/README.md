## Businesses

### Bazzly (Ce_wXQ1BJjE)
- **What:** B2B SaaS that finds Reddit posts where people describe a problem a customer's product solves and **posts recommendations automatically from Bazzly's own pool of Reddit accounts** ("we have a lot of Reddit accounts so that if something gets banned, you don't lose…").
- **Revenue (claim):** $15K MRR at recording, "over $40,000 a month" three weeks later; >1,600 signups, >100 paying customers at $15K.
- **Pricing:** single $199/mo plan + in-app usage top-ups.
- **Customers:** validated with a landing page + waitlist and cold DMs on X **before building**; then X DMs + dogfooding Bazzly on Reddit. 0→$100 MRR in month 1, but 40% churn and 2% trial-to-paid; spent 6 months talking to churned users and repositioning → churn 25%, trial-to-paid 14%, then $1K MRR; took a 50% partner with an X audience; repositioned to "no Reddit account needed" → $3K, then $7K MRR with trial-to-paid ~50% (claims). Later closed signups behind a waitlist. Build in public on X; "stack channels one by one."
- **Stack (claim):** Supabase (free), Vercel (free), Railway ($5/mo), PostHog (free); Sequenzy (email), Outrank (SEO), Bazzly itself for Reddit/"AIO."
- **Ongoing time:** full-time founder + 50% partner.

### Bustem (PoEJ9t9rUb4 + 2 Shorts)
- **What:** "productized SaaS": AI agents scan the web for copycats/counterfeits/unauthorized resellers of e-commerce brands; a human team (analysts, enforcement agents, client success) files takedowns. Weekly automated Slack summary per client.
- **Revenue (claim):** $0 → $600K/mo in just over a year, bootstrapped; 180+ brands; $1.5K–$5K/mo, ~$3K average; 50+ staff, NYC office.
- **Lesson (claim):** v1 was self-serve software given free to ~30 beta brands; none used it because takedowns are tedious. Done-for-you + "never give it away free" fixed it.
- **Ongoing time:** a staffed company. Not passive.

## Plan: monitor-only launch-thread finder for claw-shorts

### 1. Why
- Bazzly (https://www.youtube.com/watch?v=Ce_wXQ1BJjE) claims $15K→$40K MRR at $199/mo by finding threads where people describe the problem a product solves. The paying buyer is the same one claw-shorts targets: indie SaaS and dev-tool builders.
- We take the **safe half** only: find and rank threads, draft a reply, a human decides. No auto-posting, no account pools.
- It dogfoods claw-shorts' own outreach: the tool finds "launching on Show HN / need a demo video" threads.

### 2. Product
- `skills/claw-shorts/thread-finder/` in public claw-work: a local Python CLI + agent skill.
  - Input: a product blurb or README + keywords.
  - Sources (v0): **Hacker News via the public Algolia HN Search API** and **GitHub public search** (issues/discussions asking for demo-video/launch help). Reddit is **out of v0** until its Data API terms for this use are checked.
  - Output: ranked list (thread URL, why it matches, age, engagement) + a draft reply per thread under 80 words that discloses "I built this." JSON + Markdown.
  - Hard rule in code and README: it never posts, logs in, or sends anything.
- Could later be embedded as a tool on the claw-shorts static site (static demo with sample output; live search stays local CLI).

### 3. MVP scope
- One cloud-agent PR: CLI, skill doc, 10+ tests with recorded fixtures (no live network in tests), sample output for claw-shorts itself.
- Not in MVP: hosting, accounts, scheduling, Reddit, email alerts, payments.

### 4. Pricing
- Free and MIT, as a funnel into a one-time Pro Launch Kit. A paid "weekly thread digest" is a later idea only if 20+ people use the free one (EST threshold, my judgment).

### 5. Marketing
- Dogfood: run it weekly for claw-shorts; a human approves each reply draft before anything is posted.
- Question page (UNVALIDATED topic): "How to find people asking for your dev tool on Hacker News".

### 6. Outreach (small, human-approved batches)
**Who (categories; no contacts collected):** HN "Show HN" posters from the last 14 days with no demo video; GitHub repo owners whose issues ask for a demo/GIF; indie builders posting "launch week" on X.

Draft C. Subject: **Saw your Show HN** (17 chars)
> Hi {name}, I saw {project} on Show HN. Nice work. I'm building a free, open-source tool that turns a README into captioned vertical launch clips, rendered locally, no avatars. I'd like to make 3 clips for {project} for free and send them over, no strings. If they're useful, you can post them; if not, tell me what missed. Interested?
> {sender}

Draft D. Subject: **Demo clip for {repo}** (≤29 chars with a short repo name)
> Hi {name}, someone in {repo}'s issues asked for a demo video. I made a free MIT tool that renders a short captioned demo from a terminal recording or README, all local. Happy to make one for {repo} and open a PR with the file, or you can run it yourself: {link}. Want me to?
> {sender}

(Both under 100 words. Nothing sent.)

### 7. Payment collection
Not decided. The free tool needs none.

### 8. Fulfillment and support
- Free CLI; issues on claw-work GitHub. Support macros (agent-drafted): "no results for my keywords", "HN rate limit", "why no Reddit".
- Metrics to log once anything is public (from Bazzly): waitlist signups, trial/free→paid, churn, reasons from churned users.

### 9. Kill criterion
If after 4 weekly dogfood runs it surfaces <5 relevant threads total, or 0 outreach replies trace to it, stop maintaining it.
