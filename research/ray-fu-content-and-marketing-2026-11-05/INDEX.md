## Theme map

### Content systems

1. **Niche selection by RPM** — Finance explainers ($15–50 CPM) beat gaming (~$2 CPM). Optimize for content repeatability, audience size, monetization depth.
2. **Multi-agent content teams** — Strategist → Researcher → Writer → Editor → Publisher; each agent consumes only the previous agent's output.
3. **Hook & script scoring gates** — Research sweep (YouTube/Reddit/X), hook variations, independent checker scoring venture novelty + copy intensity (10/10 or rewrite).
4. **Programmatic video rendering** — Claude writes code that paints frames; Playwright captures; ffmpeg muxes. Self-critique loop until ≥8/10 per frame.
5. **OSS factories** — `darkzOGx/youtube-automation-agent` (7 agents), `zhouxiaoka/autoclip_mvp` (clipping), `remotion-dev/remotion` (React video).

### Marketing systems

1. **ICP → outreach loop** — Interview → ICP doc → discover companies (public sources) → score → personalize → human-approved send.
2. **Competitor ad hook mining** — Meta Ad Library longest-running ads → extract first-3s hooks → clone structure → Remotion/ffmpeg creatives.
3. **Always-on marketing org** — Self-host Paperclip with Strategist, Editor, Social Manager, QA; daily viral→brief→produce→QA→draft cycle.
4. **Multi-platform research** — Agent-Reach CLI for YouTube/Reddit/X/GitHub reads without paid scrapers.
5. **Landing-page speed builds** — Claude/Codex/Grok → conversion landing page in < 1 hour.

## Explicit exclusions

- **PersonaLive** — documented in repos roundup but explicitly not adapted (AI influencer constraint).
- **ElevenLabs / paid Apollo / paid Clay / paid Higgsfield / paid Arcads** — documented as what videos show; replaced with OSS alternatives.
