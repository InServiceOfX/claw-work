## Skill / workflow as presented

1. Give Claude Code a script/prompt plus raw footage (via HyperFrames, not a native Claude renderer).
2. Identify and drop bad takes and pauses.
3. Honor script-tied visual instructions (every named effect must appear).
4. Grade, caption, zoom, motion, SFX from the prompt.
5. Accept natural-language revisions ("make the captions bigger").

Again: Claude Code does not itself grade or mux video. HyperFrames / FFmpeg (or similar) does the render from an edit plan.
