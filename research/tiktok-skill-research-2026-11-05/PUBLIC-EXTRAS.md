## Brian Scully (@bridotai) — HyperFrames, save your own skill
- HyperFrames is open source from HeyGen: install with `npx skills add heygen-com/hyperframes`
- Docs: https://help.heygen.com/en/articles/15001510-hyperframes-x-heygen
- Needs Node 22+ and FFmpeg. Preview: `npx hyperframes preview`. Render: `npx hyperframes render`. Init: `npx hyperframes init my-video`
- Public related skills: https://github.com/assafkip/claude-video-editor (skills/hyperframes/SKILL.md), https://github.com/nopefallacy/vertical-video-editing-skills
