## Business breakdowns (long-form)
### PeptIQ (B7b_2LaWOzs)
- **Built:** iOS tracker for peptide schedules, doses, reconstitution calculator, blood work, journal, interaction checker, community, and an AI Q&A using the user's own data.
- **Founder:** software engineer ~25 years; works as a fractional CTO; built this **on the side**.
- **Customers:** **SEO**. Wrote question-answer articles (AI-assisted, some self-written, some hired writers) on what people ask on Reddit/Instagram/TikTok; validated the trend with Google Trends. Claims 590k clicks to blog articles in 12 months; SEO took **6–7 months** to pay off. Key tactic: **embed a working tool in the article** (reconstitution calculator) that saves into an account, converting readers into app users. Also: schema markup, fast pages, SEMrush/Ahrefs for competitor gaps, submit sitemap to Bing.
- **Pricing:** hard paywall, ~$30/mo or ~$130/yr (RevenueCat).
- **Stack:** Expo, React Native, TypeScript, Supabase, RevenueCat, Vercel (site), PostHog, Sentry; MVP vibe-coded in ~1 week.
- **Ongoing time:** n/s; framed as a side project with little time.
- **Category lesson:** entered a crowded category already proven by GLP-1 apps and differentiated via reviews/Reddit research.

### GetEbook (P3RVeg8YCg0)
- **Built:** web app that turns an idea into a complete formatted ebook, workbook, lead magnet or coloring book.
- **Founder:** runs a social-media marketing agency; was already selling ebooks manually and as an affiliate.
- **Customers:** **Meta ads**: high creative volume, many angles/landing pages per segment (e.g. KDP sellers), constant creative refresh; started at ~$200/day ad spend.
- **Pricing:** subscription from $29/mo + one-time credit packs + upsold tutorials/digital products.
- **Stack:** Lovable v1, rebuilt with Claude Code; Supabase, Vercel, Resend, OpenAI and Gemini APIs.
- **Ongoing time:** n/s; side project next to the agency, but paid-ads scaling implies constant creative work.

## Part 2. Launch plan add-on: "question page + free tool" SEO funnel for the claw-shorts Launch Kit

**Status:** DRAFT (2026-11-16). Nothing launched, posted, emailed, signed up for, or bought. Every public, paid, or outbound step needs maintainer sign-off.
**Inputs:** Part 1 above; claw-work `Skills/claw-shorts` (Launch Kit merged, PR #9).
**Honesty:** revenue figures are founders' on-camera claims. No search-volume data was pulled; every keyword below is an **unvalidated guess**. SEO is slow: the PeptIQ founder says it took **6–7 months** to pay off. Expect little or no revenue in the first two quarters.

## 1. Why this, why now
- **Evidence:** PeptIQ (https://www.youtube.com/watch?v=B7b_2LaWOzs): side project by a 25-year software engineer, ~70% of clicks and revenue from Google (claim), grown by answering real questions and **embedding a working calculator in the article** that saves into the app. Same channel pattern as Excel Exercises, Vaultaire, AngelMatch (11-08 pass).
- **Fit:** pages and tools are static, agent-written, and run without daily attention. No ad spend (GetEbook's $20–30k/mo Meta budget is the opposite of our constraints). No new product: it feeds the existing Launch Kit.
- **Why now:** the Launch Kit plan's agent SEO loop was sequenced last. Given the 6–7 month lag, starting it alongside the build gets the clock running earlier.

## 2. Product (what gets built)
1. **Free in-browser "Launch Shorts planner"** (static HTML/JS, no server, no API calls, no tracking beyond optional privacy-friendly counts later): paste a README or product blurb → get 5 hook options, a 5-Short shot list, caption text, and the exact `claw_shorts.py launch` command. Mirrors the Launch Kit's plan output. CTA: "render these locally with the free claw-shorts skill"; Pro upsell link stays hidden until payments are decided.
2. **Two tiny utility tools** that answer common technical questions: a 9:16 **safe-zone checker** (drop a frame, see caption danger zones) and an **ffmpeg/asciinema command builder** (terminal cast or screen recording → captioned vertical MP4).
3. **8 question pages**, each answering one question and embedding one of the tools plus a real rendered example from public InServiceOfX repos (claw-work, claw-dj).

### Candidate question topics (UNVALIDATED; check Google Trends / Search Console before writing)
1. How to make a launch video for a GitHub repo
2. How to make a Show HN / Product Hunt demo video
3. How to turn a terminal recording (asciinema) into an MP4 for social
4. How to make a vertical 9:16 screen recording with ffmpeg
5. How to add captions to a screen recording locally (Whisper)
6. Safe zones for captions on YouTube Shorts, TikTok, Reels
7. What to show in a 30-second dev-tool demo
8. How to make launch Shorts without AI avatars or a subscription

## 3. MVP scope
- Agent-built PR in public claw-work under `Skills/claw-shorts/site/`: planner + 2 tools + 3 of the 8 pages, with schema markup, a sitemap, fast static pages, and tests for the planner's JSON output.
- **Not in MVP:** hosting it publicly, accounts, email capture, analytics, payments. Publishing (e.g. GitHub Pages, $0) is a separate yes.
- Agent time EST: 1 cloud-agent PR. Maintainer review EST: ~20 min.

## 4. Pricing (unchanged from the 11-08 plan, one tweak)
- Free tools and free OSS engine. Pro one-time **$39 EST** list.
