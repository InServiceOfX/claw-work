## Published request

Build a Finder-inspired Ubuntu file browser. As a user, queue places
automatically while visiting them, and also pin favorites manually (right-click
or drag). Copy a full path so it can be pasted into a terminal. Show hidden
files by default. Offer a short path field that accepts an absolute path, a
home-relative path, or a path relative to the current folder and opens it
immediately. Sort by Name, Modified, and Size. Support skins and a
user-selected background image.

## Examples

- A deep nested directory should be reachable again after one visit, and can
  also be pinned manually.
