About

claw-shorts is a free, open-source toolkit for creating vertical short-form videos (YouTube Shorts, TikTok, Reels). It's designed for developers and indie makers who want to promote their projects without learning video editing.

These web tools work entirely in your browser—no data is sent to any server. For rendering videos locally, use the claw_shorts.py Python script or the Rust tools in the claw-work repository.

Features

  • Generate launch video plans from README files
  • Check caption safe zones for all major platforms
  • Build ffmpeg commands for scaling, padding, and captioning
  • Convert terminal recordings (asciinema) to vertical videos
  • No accounts, no cloud services, no tracking
  • MIT licensed, fully open source
