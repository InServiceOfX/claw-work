How to Make a Launch Video for a GitHub Repo

A 5-Short launch series can introduce your open source project to developers who scroll TikTok, YouTube Shorts, or Instagram Reels. Each Short targets a different angle: overview, installation, demo, features, and a call to action.

This guide walks through the process using the free claw-shorts toolkit, which renders videos locally without accounts or cloud services.

What You'll Create

  • Short 1: Hook + project overview (15-30s)
  • Short 2: Installation walkthrough (20-45s)
  • Short 3: Quick demo showing the tool in action (30-60s)
  • Short 4: Top features or use cases (30-45s)
  • Short 5: Call to action with README scroll (15-30s)

Step 1: Prepare Your README

The planner extracts project info from markdown. For best results, include:

  • A clear # Project Name heading
  • A one-line tagline or description
  • A ## Features section with bullet points
  • A ## Installation section with a code block
  • A ## Usage section with example commands

Step 2: Generate Your Launch Plan

Paste your README into the planner below. It will generate:

  • 5 hook options to grab attention
  • A shot list for all 5 Shorts
  • Caption text for each video

Step 3: Record Source Clips

Before rendering, you need raw footage for each Short:

  • Screen recordings: Use OBS, QuickTime, or any screen recorder
  • Terminal sessions: Record with asciinema
  • Static frames: Screenshots work for simple overlays

Organize clips in folders: input/short1/, input/short2/, etc.

Step 4: Render with claw_shorts.py

Clone the claw-work repository and run the generated commands: 

git clone https://github.com/InServiceOfX/claw-work.git
cd claw-work/skills/claw-shorts

# Check dependencies
python3 scripts/claw_shorts.py doctor

# Run each render command from your plan
python3 scripts/claw_shorts.py render \
  --input input/short1/ \
  --output output/ \
  --template hook_reveal \
  --title "My Project Overview" \
  --hook "My Project in 30 seconds" \
  --cta "Follow for more"

Each render outputs a 1080×1920 MP4 at 30fps plus a JSON sidecar with metadata, suggested captions, and hashtags.

Step 5: Review and Post

Before uploading:

  • Watch each video end-to-end
  • Check that text stays within safe zones (use the checker)
  • Verify audio levels (target -14 LUFS for consistent playback)
  • Add any missing disclosures (synthetic voice, etc.)

Upload to YouTube Shorts, TikTok, and/or Instagram Reels. Space them out over a few days or post all at once—test what works for your audience.

Example: claw-dj Launch

The claw-dj audio toolkit used this approach for its launch. The 5-Short series covered:

  1. "claw-dj in 30 seconds" — hook + overview
  2. "Installing claw-dj" — cargo install walkthrough
  3. "Stem separation demo" — splitting a track into vocals/drums/bass/other
  4. "3 claw-dj features" — step breakdown of key capabilities
  5. "Get claw-dj" — README scroll with link

Each video was rendered locally with claw_shorts.py, reviewed for safe zones and audio levels, then uploaded manually.
