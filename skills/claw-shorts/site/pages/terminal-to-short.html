How to Turn a Terminal Recording into a Vertical MP4

Terminal demos are perfect for dev-tool Shorts: quick, focused, and immediately useful. This guide shows how to convert an asciinema recording to a 1080×1920 vertical MP4 ready for YouTube Shorts, TikTok, and Instagram Reels.

Prerequisites

  • asciinema — terminal recorder
  • agg — asciinema GIF generator
  • ffmpeg — video encoder
# macOS
brew install asciinema ffmpeg
cargo install --git https://github.com/asciinema/agg

# Ubuntu/Debian
sudo apt install asciinema ffmpeg
cargo install --git https://github.com/asciinema/agg

Step 1: Record Your Terminal

Use asciinema to capture your session: 

asciinema rec demo.cast

Tips for a good recording:

  • Clear your terminal first (clear or Ctrl+L)
  • Use a simple prompt (hide long paths)
  • Type at a readable pace—you can speed up later
  • Keep it under 60 seconds for Shorts
  • Press Ctrl+D or type exit to stop

Step 2: Convert to GIF with agg

agg renders the cast file to an animated GIF. Use vertical-friendly settings: 

agg \
  --cols 60 \
  --rows 40 \
  --font-size 24 \
  demo.cast \
  demo.gif

These settings create a narrower, taller terminal view that fits better in a 9:16 frame. Adjust --rows if your demo needs more vertical space.

Step 3: Convert GIF to Vertical MP4

Use ffmpeg to scale and pad the GIF to 1080×1920: 

ffmpeg -y \
  -i demo.gif \
  -movflags faststart \
  -pix_fmt yuv420p \
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:black" \
  -r 30 \
  demo_vertical.mp4

This command:

  • Scales to fit within 1080×1920 while preserving aspect ratio
  • Pads with black bars to fill the frame
  • Outputs H.264 video at 30fps (standard for Shorts)

Step 4: Add Hook and CTA (Optional)

For a polished Short, add a hook card at the start and a CTA at the end. The claw_shorts.py terminal_typer template does this automatically: 

python3 claw_shorts.py render \
  --template terminal_typer \
  --cast demo.cast \
  --output output/ \
  --title "Quick CLI Demo" \
  --hook "Watch this terminal trick" \
  --cta "Follow for more"

This wraps your terminal recording with:

  • A 2-second hook card with your text
  • Your terminal recording, scaled and padded
  • A 3-second CTA card at the end

Example: claw-work CLI Demo

Here's a real example from the claw-work repository. This demo shows running claw_shorts.py doctor to check dependencies:

  1. Record: asciinema rec doctor-demo.cast
  2. Run the doctor command during recording
  3. Convert: agg --cols 60 --rows 40 --font-size 24 doctor-demo.cast doctor-demo.gif
  4. Encode: ffmpeg -i doctor-demo.gif -vf "scale=1080:1920:..." -r 30 doctor-demo.mp4
  5. Or use the template: python3 claw_shorts.py render --template terminal_typer --cast doctor-demo.cast ...

The result is a clean, vertical video showing the CLI in action—perfect for a "here's how to check if your setup is ready" Short.

Tips for Terminal Shorts

  • Use a dark theme: High contrast text on dark background reads well on mobile
  • Increase font size: --font-size 24 or higher for readability
  • Keep it short: 15-45 seconds is ideal for Shorts
  • Add context: A hook card explains what viewers are about to see
  • Test on mobile: Watch on a phone before posting

Troubleshooting

agg not found

Install with Cargo:

cargo install --git https://github.com/asciinema/agg

Make sure ~/.cargo/bin is in your PATH.

GIF is too fast/slow

asciinema recordings play back at the same speed you typed. To adjust: 

# Speed up 2x
agg --speed 2 demo.cast demo.gif

# Slow down to 0.5x
agg --speed 0.5 demo.cast demo.gif

Output has wrong colors

Specify a theme that matches your terminal: 

agg --theme monokai demo.cast demo.gif

Available themes: asciinema, monokai, solarized-dark, solarized-light, and more.
