Requires OpenAI Whisper installed locally.

Prerequisites

  • ffmpeg: brew install ffmpeg or apt install ffmpeg
  • agg (for .cast files): cargo install --git https://github.com/asciinema/agg
  • Whisper (optional, for captions): pip install openai-whisper

All processing runs locally on your machine. No files are uploaded anywhere.
